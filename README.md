Game Mechanics: 
Bullet hell survival game, try to survive the bullets or succumb to an untimely death. You will be granted 1 of 4 characters upon spawn (completetly random) Each with certain attirbutes to help you survive. Bullets damage ranges so it can iether be a blessing or a curse. Lootboxes spawn throughout the map granting certain powerups. Open the chat system to yap with your friends.

Characters: 
Gojo (Gojo) - 10,000 shield, 120 hp. The strongest for a reason. If damage is two weak then "Nah I'd Win" 
Shikeru (Gambler) - Gambling is his life, which can sometimes let him avoid strife. 30% chance to avoid taking damage from sources 
Koro-sensei (Assassin) - Simple mechanic; faster movement speed
Escanor (tank) - Tanky man, but slower on the run

Game Mechanic:
Surive as long as possible from the bullet storm. Each bullet can do random damage so we have no clue what will happen if you get hit. Each bullet attack pattern has a specific pattern. Some are a vortex, others diagonal out the screen. 
Move aroudn the map dodging bullets as long as possible and collect powerups to apply buffs to your character. They will spawn randomly around the map so be wary. 

Chat:
